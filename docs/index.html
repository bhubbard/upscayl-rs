04 // PURE-RUST ARCHITECTURE ZERO UNSAFE CODE

src/engine/software.rs

Implements separable FilterType::Lanczos3 super-resolution followed by enhance_details(img, amount, radius) adaptive unsharp masking for sub-pixel edge contrast reconstruction.

src/engine/native.rs

Auto-discovers upscayl-bin across Linux, macOS, and Windows paths, spawning Vulkan GPU inference with real-time stderr percentage regex capture and --double 16x chaining.

src/tiling.rs

Computes VRAM-safe TileRect grids with configurable overlap margins and composites upscaled patches using bilinear seam feathering (Tiler::blend_tile) to eliminate tile boundary artifacts.

src/batch.rs

Recursively traverses directories via WalkDir and executes multithreaded batch upscaling across all CPU cores with rayon::prelude::ParallelIterator and atomic progress counters.
